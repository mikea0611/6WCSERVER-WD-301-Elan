# ÉLAN – Online Dress Rental Web Application

**Course:** 6WCSERVER – Web Server Application

**Category:** Shopping

**Technology Stack:** MongoDB, Express.js, Vue.js, Node.js (MEVN)

## Project Introduction

ÉLAN is a proposed online dress rental web application designed to provide customers with a convenient way to browse and rent dresses for different occasions. The application aims to make dress rentals more accessible by allowing users to explore available dresses, view product details, and select their preferred items through an organized online platform.

The project focuses on creating a user-friendly rental experience with a clean and responsive interface. It will be developed using the MEVN stack, consisting of MongoDB, Express.js, Vue.js, and Node.js.

## Project Objectives

The main objective of ÉLAN is to develop a user-friendly online dress rental web application using the MEVN stack that allows customers to conveniently browse dress collections, view rental information, and select dresses for different occasions through an organized online platform.
